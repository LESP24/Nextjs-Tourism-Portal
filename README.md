# 🗺️ Tzimol Cultural Mapper

> A digital tourism and community reporting platform designed to map, promote, and preserve the regional cultural assets of the Tzimol municipality in Chiapas. Developed as a core technological initiative for a community social service program launching in August 2026.

## 💻 Tech Stack
* **Frontend Framework:** Next.js (React)
* **Language:** TypeScript
* **Headless CMS & Database:** Sanity.io
* **Styling:** Tailwind CSS *(Ajusta esto si usaste otra librería de estilos)*

## 🚀 Key Features
* **Cultural Asset Mapping:** Interactive visualization of historical and touristic points of interest within Tzimol.
* **Community Reporting Portal:** A dedicated interface for locals and tourists to report updates or discover new attractions.
* **Dynamic Content Management:** Fully integrated with Sanity.io, allowing non-technical users to update tourism data, images, and descriptions in real-time without touching the code.
